# Architecture Decision Records (ADR)

Each significant technical decision is captured here using the template:

- **Context** — what triggered the decision.
- **Decision** — what was chosen.
- **Reason** — why this option was selected.
- **Alternatives** — what was considered and rejected.
- **Impact** — consequences (positive and negative) and follow-ups.

Records are immutable. To revise a decision, create a new ADR that
supersedes the previous one.
