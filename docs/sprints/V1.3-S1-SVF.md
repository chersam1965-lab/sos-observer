# Sprint V1.3-S1 — Scientific Validation Framework

**Branch:** `GSOS-Observer-V1.3-DEV`
**Precedes:** TD-001, TD-002, TD-003 (queued, untouched)
**Status:** Implemented — awaiting field QA

## Objective

Build an independent Scientific Validation Framework so GSOS Observer
results can be measured against expert ground truth, aggregated, and
exported as a formal scientific report for universities, research
centers, and innovation juries.

No change to the analysis engine, indicators, dashboard, Analysis PDF
pipeline, or Pilot module.

## Deliverables (shipped)

- Independent domain `src/lib/scientific/`: `types`, `match` (deterministic
  formula), `LocalStorageScientificRepository`, DI hook, `ScientificService`
  with aggregation.
- Storage isolated in `gsos.scientific.experiments.v1` — no overlap with
  analysis / pilot keys.
- New route `/scientific` (auth-gated, `noindex`):
  - New Experiment form (objective, case type, case description, input
    data, GSOS snapshot, ground truth, evaluator notes).
  - Aggregate KPIs: total experiments, success rate, average match rate,
    matches vs. total.
  - Match distribution bar (match / partial / mismatch).
  - Performance-over-time (weekly buckets).
  - Recent experiments table.
- Scientific Validation Report PDF export — 6 sections (Executive
  summary, Statistical results, Strengths, Weaknesses, Recommendations,
  Improvement plan) populated from aggregates. Filename
  `GSOS-Scientific-Validation-Report-YYYY-MM-DD-HH-MM.pdf`.
- Full EN / FR / AR translations with RTL support (additive keys only).
- Unit tests: 7 new tests, 37 total green.
- ADR-0005, TECH_DEBT update, CHANGELOG entry.
