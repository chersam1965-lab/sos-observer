# Sprint Documentation

Each sprint on `GSOS-Observer-V1.3-DEV` produces two documents:

- `NN-<slug>-plan.md` — **before** the sprint. Contains: Sprint Plan,
  Expected Deliverables, Risk Assessment.
- `NN-<slug>-qa.md` — **after** the sprint. Contains: QA Report,
  Test Report summary, CHANGELOG diff pointer, Tech Debt diff pointer.

Numbering restarts at `01` inside the V1.3 branch. See
`docs/branches/V1.3-DEV.md` for the branch charter and
`docs/BRANCHING.md` for the overall workflow.
