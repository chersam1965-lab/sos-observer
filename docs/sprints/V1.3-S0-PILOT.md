## Objective

Collect real-world evidence of GSOS Observer performance before resuming
technical-debt work. No change to the analysis engine, indicators,
report pipeline, or existing i18n dictionaries.

## Deliverables (shipped)

- Pilot Mode toggle (localStorage `gsos.pilot.enabled`) in dashboard header.
- Independent Pilot repository (`src/lib/pilot/`): types, LocalStorage
  provider with DI hook, service with aggregation, mode flag helpers.
- Session logging on every Pilot analysis (session id, analysis id,
  report id, timestamp, language, indicators, global status, app version).
- Post-analysis Feedback form (accuracy 1–5, usefulness 1–5, notes,
  suggestions) rendered under the Analysis panel; EN/FR/AR + RTL.
- Pilot Dashboard route `/pilot`: totals, averages, status &
  language distribution, top keywords, recent sessions table.
- Pilot Validation Report PDF export from the Pilot Dashboard.
- Unit tests: 11 new tests, 30 total green.
- ADR-0004, TECH_DEBT update, CHANGELOG entry.
