# Sprint V1.3-S2-GKE — Knowledge Extraction Engine

**Branch:** `GSOS-Observer-V1.3-DEV`
**Status:** Implemented — awaiting QA sign-off.
**ADR:** [ADR-0006](../adr/0006-knowledge-extraction-engine.md)

## Scope

Deliver an isolated, read-only Knowledge Extraction Engine (GKE) that
transforms existing project artefacts into structured, versioned,
publishable knowledge documents. No change to Analysis, Pilot, or
Scientific Validation.

## Deliverables

- `src/lib/knowledge/` domain (types, DI repository, extractors,
  engine, generator, PDF, service, default sources loader).
- `src/routes/knowledge.tsx` — Knowledge Center page: versions list,
  six-tab document viewer, full-text search, per-document PDF export,
  manual "Extract now" trigger.
- i18n additions: `kc.*` keys in EN / FR / AR (RTL preserved).
- ADR-0006 and this sprint plan; CHANGELOG and TECH_DEBT updates.
- Unit tests: `engine.test.ts`, `generator.test.ts`, `service.test.ts`.

## Acceptance checklist

- [x] Analysis engine, indicators, main Dashboard, PDF pipeline, Pilot
      and Scientific Validation modules unchanged.
- [x] Extraction produces a `KnowledgeVersion` with items in every
      applicable category and six generated documents.
- [x] Version IDs auto-increment per sprint code; prior versions are
      never deleted.
- [x] `/knowledge` renders version list, six document tabs, search,
      and PDF export.
- [x] Storage isolated under `gsos.knowledge.versions.v1`.
- [x] Unit tests added; all previous tests remain green.
