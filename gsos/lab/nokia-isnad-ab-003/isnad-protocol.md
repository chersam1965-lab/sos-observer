# GSOS-ISNAD Protocol — Preregistered Rules

ISNAD is used only as a methodological source-criticism layer.

It maps:

1. source identity;
2. publication time;
3. retrieval time;
4. source quality;
5. corroboration;
6. contradiction;
7. internal consistency;
8. provenance continuity.

ISNAD must NOT:
- use post-cutoff information;
- change the declared target;
- change the scoring rule;
- delete unfavorable evidence;
- convert inference into fact;
- substitute for statistical validation.

The A/B test must use the same evidence pool and same historical cutoff.
The only preregistered difference is the source-criticism layer.
