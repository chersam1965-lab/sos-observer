# معمارية GSOS

## الطبقات الأساسية

GSOS يتكون من:

1. Core Identity
2. Kernel
3. Runtime
4. Services
5. Cloud
6. Sync
7. Bootstrap
8. Knowledge Library

## العلاقة

Kernel يدير التشغيل.

Runtime يدير دورة الحياة.

Services تقدم الوظائف.

Cloud يحافظ على الاتصال الخارجي.

Bootstrap يعيد بناء البيئة.

Knowledge Library تحفظ تاريخ وفلسفة النظام.
